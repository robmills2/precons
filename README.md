# precons (moved)

REM's Commander Decks moved to https://robmills2.github.io/decks/ in November 2026, when the repository that used to have this name was renamed robmills2/decks. Edit the pages there.

This repository only keeps the old links working:

- https://robmills2.github.io/precons/ forwards to https://robmills2.github.io/decks/precons/
- https://robmills2.github.io/precons/decks/ forwards to https://robmills2.github.io/decks/constructed/
- Any other address here forwards to https://robmills2.github.io/decks/

A link to one deck, the part after #, comes along, so https://robmills2.github.io/precons/decks/#splinter-group lands on https://robmills2.github.io/decks/constructed/#splinter-group.
